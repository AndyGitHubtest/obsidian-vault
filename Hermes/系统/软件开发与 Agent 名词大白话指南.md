# 💻 软件开发与 Agent 名词大白话指南

> [!abstract] 💡 核心记忆法
> * **软件开发** 🏗️ = **盖大楼**（设计、施工、验收、物业）
> * **AI Agent** 🤖 = **全能管家**（大脑、手脚、记忆、工具）
> * **量化交易** 📉 = **自动提款机**（找规律、造机器、盯着它）

---

## 🏗️ 一、软件开发全流程（盖大楼逻辑）

> [!TIP] 场景：从画图纸到剪彩开业，一环扣一环。

### 📋 阶段 1：需求与设计（想清楚再动手）

| 黑话 | 大白话 (比喻) | 一句话解释 |
| :--- | :--- | :--- |
| **PRD (需求文档)** | 📜 **施工图纸** | 产品经理写的“说明书”。长什么样、逻辑是什么，全写在这。没图纸就动工，楼肯定歪。 |
| **MRD (市场需求文档)** | 📊 **商业计划书** | 论证“这楼盖了能不能租出去”。分析市场、对手、能不能赚钱。 |
| **Wireframe (线框图)** | 📐 **毛坯房草图** | 用黑白线条画个大概布局，确定哪里是卧室、哪里是厕所。先别管美丑，先看位置。 |
| **Prototype (原型)** | 🏠 **精装样板间** | 可以点、可以交互的 Demo。虽然不能真住（没后台），但能模拟真实体验。 |
| **UI (用户界面)** | 🎨 **室内软装** | 颜色、字体、图标。负责让房子看起来“高大上”。 |
| **UX (用户体验)** | 🛋️ **居住舒适度** | 住得舒不舒服？开关顺手吗？动线合不合理？ |

### 💻 阶段 2：核心开发（撸起袖子干活）

| 黑话 | 大白话 (比喻) | 一句话解释 |
| :--- | :--- | :--- |
| **Frontend (前端)** | 🚪 **门面工程** | 砌墙、刷漆、装门窗。你看得到的所有界面，HTML/CSS/JS 是三大件。 |
| **Backend (后端)** | ⚡ **水电管网** | 埋在墙里的管线。负责供水供电（数据流转），虽然看不见，断了就瘫痪。 |
| **Database (数据库)** | 🗄️ **地下室仓库** | 存东西的。用户信息、订单、库存，全在这儿。 |
| **API (接口)** | 📞 **内部对讲机** | 前台（前端）和厨房（后端）沟通的专线。前台下单，厨房接单。 |
| **Git (版本控制)** | 🎮 **游戏存档** | 每次改代码存个档。改崩了？回滚到昨天的存档就行。 |
| **Branch (分支)** | 🌿 **平行宇宙** | 主代码是“主宇宙”。你要加新功能，开个“分支”在平行宇宙里改，改好了再合并。 |
| **Pull Request (PR)** | 📮 **合并申请** | “报告队长，我在平行宇宙改好了，申请合并到主宇宙，请审核。” |

### 🧪 阶段 3：测试与验收（找茬与把关）

| 黑话 | 大白话 (比喻) | 一句话解释 |
| :--- | :--- | :--- |
| **QA (质量保证)** | 🕵️ **专业质检员** | 专门找 Bug 的人。他们会想方设法把系统搞崩，证明楼没质量问题。 |
| **Unit Test (单元测试)** | 🔍 **零件体检** | 还没组装呢，先测每个零件（函数）是不是好的。比如测“计算器”的加法对不对。 |
| **Bug (缺陷)** | 🐛 **质量瑕疵** | 墙裂了、水管漏水。按严重程度分 P0 (楼要塌了) 到 P3 (墙皮有点脱落)。 |
| **UAT (验收测试)** | 👨‍👩‍👧 **业主验房** | 代码测完了，让真正的业主（客户/老板）上来试用。业主点头才算过关。 |

### 🚀 阶段 4：上线与运维（开业与物业）

| 黑话 | 大白话 (比喻) | 一句话解释 |
| :--- | :--- | :--- |
| **Deploy (部署)** | 🔑 **剪彩开业** | 把在测试服（样板间）跑通的代码，正式推到生产服（真正的大楼）。 |
| **Production (生产环境)** | 🏢 **真实营业的大楼** | 真金白银在跑的地方。在这里操作要极其小心，弄坏了就是事故。 |
| **Log (日志)** | 📹 **监控录像** | 系统里发生的所有事都有记录。出事了查 Log，看看到底哪一步卡住了。 |
| **Hotfix (热修复)** | 🚑 **紧急抢修** | 上线后发现重大 Bug，不能等明天，必须马上停机修补，修完立马重启。 |
| **CI/CD (流水线)** | 🤖 **自动化机器人** | 代码一提交，机器人自动跑测试、打包、推上线。全程无需人工干预。 |

## 🤖 二、AI Agent（全能管家逻辑）

> [!NOTE] 场景：你雇佣了一个高智商管家，给他配工具，让他帮你干活。

| 黑话 | 大白话 (比喻) | 一句话解释 |
| :--- | :--- | :--- |
| **LLM (大模型)** | 🧠 **管家的大脑** | 懂很多道理，能思考。但如果没有手脚，只能陪你聊天，干不了活。 |
| **Agent (智能体)** | 🦾 **有手脚的管家** | **LLM + 工具调用**。能帮你操作电脑、下单、改代码。 |
| **Prompt (提示词)** | 📝 **任务指令单** | 你写给管家的话。指令越清晰，管家干得越好。 |
| **Tool (工具)** | 🧰 **扳手和螺丝刀** | 管家自带的技能。比如“搜索 Google"、“读取文件”。 |
| **Memory (长期记忆)** | 📒 **管家记事本** | 管家的小本本。记着你的偏好（比如“用 Python"），下次不用你提醒。 |
| **Sandbox (沙盒)** | 🧪 **隔离实验室** | 让管家在里面做实验，就算炸了，也不会伤到你电脑里的核心数据。 |

## 🌍 四、欧美量化公司专属：软件、术语与黑话

> [!info] 场景：在纽约、伦敦、芝加哥的写字楼里，从早上 7 点盯盘到下午 4 点。

### 💻 欧美圈专用软件（区别于国内的工具）

| 软件 | 大白话 (比喻) | 为什么欧美公司爱用？ |
| :--- | :--- | :--- |
| **Bloomberg (BBG)** | 💳 **金融圈黑卡** | 不仅仅是数据，更是**社交网络**。你有 BBG 账号，才能和其他机构交易员聊天。 |
| **FactSet** | 📊 **基本面显微镜** | 做基本面量化（Fundamental Quant）的首选，财报数据清洗得比 Bloomberg 还干净。 |
| **kdb+** | 🐙 **时间序列八爪鱼** | 欧美大行标配数据库。处理带时间戳的数据（Tick 级）极快，快得离谱，但语言很难写。 |
| **Slack** | 💬 **工作微信群** | 欧美不用微信/钉钉。所有报警、代码 Review、交易信号都推送到 Slack Channel。 |
| **AWS / GCP** | ☁️ **云端机房** | 欧美公司很少自己买服务器，全在云上。算力不够？一键起 1000 台机器回测。 |
| **Vim / Neovim** | ⌨️ **极客键盘** |  Jane Street 等高频公司的信仰。手指不离开键盘，看着像弹钢琴一样写代码。 |
| **Jira** | 🎫 **催命符** | 任务管理系统。你的老板会在这里给你派活，没做完？红票一直亮着。 |

### 🗣️ 欧美量化核心术语 (The Lingo)

#### 1. 岗位划分 (Who are you?)
*   **Quant Researcher (QR)**
    *   *大白话*：**军师**。
    *   *解释*：天天看论文、挖因子、找规律。数学好、PhD 多。
*   **Quant Developer (QD)**
    *   *大白话*：**工匠**。
    *   *解释*：把军师的想法变成代码。C++/Python 大神，负责系统稳定。
*   **Quant Trader (QT)**
    *   *大白话*：**操盘手**。
    *   *解释*：盯着盘面的，控制风险，决定什么时候把钱打出去。

#### 2. 策略与类型 (How we make money?)
*   **Prop Trading (自营交易)**
    *   *大白话*：**花自己的钱赌**。
    *   *解释*：公司自己的钱，赚了分得多（20%-50%），亏了扣奖金。压力极大，但最自由。
*   **Market Making (做市)**
    *   *大白话*：**赚买卖差价的中间商**。
    *   *解释*：我不赌方向，我两边都挂单，你买我卖，赚那 1 个 Tick 的差价。高频公司（HFT）最爱。
*   **Stat Arb (统计套利)**
    *   *大白话*：**找两个长得像的兄弟打架**。
    *   *解释*：两个相关性高的资产，价差偏离了就做空贵的、买便宜的，等它们回归。

#### 3. 职场黑话 (Slang)
*   **PnL (Profit and Loss)**
    *   *大白话*：**今天赚了几个亿/亏了裤衩**。
    *   *解释*：每天盯着看的数字。PnL 是红是绿决定了你的心情。
*   **Alpha Decay**
    *   *大白话*：**策略烂了/过期了**。
    *   *解释*：以前赚钱的规律，现在不灵了。因为别人也发现了。
*   **In the red / In the green**
    *   *大白话*：**亏麻了 / 赚翻了**。
    *   *解释*：红色代表亏损（欧美习惯），绿色代表盈利。
*   **Desk**
    *   *大白话*：**山头**。
    *   *解释*：指一个具体的交易团队。比如 "I'm on the Macro Desk"（我在宏观策略组）。
*   **Buy-side / Sell-side**
    *   *Buy-side*（买方）：对冲基金、资管。手里有**钱**，想投资赚钱。
    *   *Sell-side*（卖方）：高盛、大摩。手里有**产品/服务**，想卖给买方。
*   **Bleeding**
    *   *大白话*：**大出血**。
    *   *解释*：策略一直在亏钱，止损止不住。

## 📈 五、量化交易“牛马”常用兵器谱

> [!warning] 场景：从找数据到造策略，再到实盘厮杀，全靠这些家伙事儿。

### 🔍 1. 投研与数据（找原料的）

| 软件名称 | 大白话 (比喻) | 干嘛用的？ |
| :--- | :--- | :--- |
| **Wind (万得)** | 💳 **VIP 贵族卡** | 国内金融圈标配。查宏观数据、看新闻、扒财报。除了贵没毛病，那是金融界的“百度”。 |
| **Bloomberg** | 🌍 **全球通行证** | 国际版 Wind。做美股、外汇、Crypto 必备。两万美金一年，有钱人的入场券。 |
| **Tushare / AKShare** | 🐟 **免费海鲜市场** | 穷小子的 Wind。Python 库，免费抓数据。虽然有时候会断流、数据脏点，但省钱啊！ |
| **Kaggle** | 🎓 **刷题网** | 找现成的数据集练手。别人洗好的数据直接拿来跑模型。 |

### 💻 2. 策略开发（造机器的）

| 软件名称 | 大白话 (比喻) | 干嘛用的？ |
| :--- | :--- | :--- |
| **Jupyter Notebook** | 📓 **草稿纸** | 写几行代码看一眼结果。适合做研究、画图、试想法。跑实盘绝对不能用这个（太乱）。 |
| **PyCharm** | 🏭 **重型机床** | 专业的 Python 编程软件。写大项目、重构代码、查错必用它。工业级标准。 |
| **VS Code** | 🔪 **瑞士军刀** | 轻量级编辑器。什么语言都能写，插件多，启动快。现在比 PyCharm 还火。 |
| **Docker** | 📦 **标准集装箱** | 把你写的策略和运行环境（Python 版本、依赖包）全打包。换台电脑直接跑，绝不报错“缺环境”。 |

### ⚡ 3. 实盘与交易（开机器的）

| 软件名称 | 大白话 (比喻) | 干嘛用的？ |
| :--- | :--- | :--- |
| **CTP (SimNow)** | 📞 **交易所热线** | 国内期货交易的接口。你的策略必须通过这根线才能把单子报给交易所。 |
| **Redis** | 🧠 **超级速记本** | 内存数据库。速度极快！把最新的行情、持仓存在这，微秒级读写。 |
| **Kafka** | 🏭 **传送带** | 消息队列。行情数据像流水线一样哗啦啦过来，Kafka 负责排队分发，不拥堵。 |
| **Grafana** | 📺 **老板监控屏** | 可视化大屏。策略赚没赚钱、服务器 CPU 高不高、有没有断网，全画成图表给你看。 |
| **Nautilus / VeighNa** | 🏗️ **造车底盘** | 现成的量化交易框架。不用从零写怎么连交易所、怎么下单。站在巨人的肩膀上。 |

### 🧹 4. 办公与摸鱼（保命的）

| 软件名称 | 大白话 (比喻) | 干嘛用的？ |
| :--- | :--- | :--- |
| **Excel** | 📉 **最后的倔强** | 别看不起它。再复杂的模型，最后往往都要导出到 Excel 里给老板看一眼。万能胶水。 |
| **Obsidian / Notion** | 📚 **外脑** | 记笔记、存策略逻辑、建 Wiki。人脑记不住那么多细节，全靠它。 |

## 🎬 四、项目管理与协作（把项目比作“剧组拍戏”）

> [!tip] 场景：导演（PM）、编剧（开发）、制片（老板）一起把戏拍完。

| 黑话 | 大白话 (比喻) | 一句话解释 |
| :--- | :--- | :--- |
| **Agile (敏捷开发)** | 🏃 **边拍边改模式** | 不等到最后才看全片。拍一集看一集，观众（客户）觉得不好立马改下一集。 |
| **Sprint (冲刺)** | 🗓️ **拍摄周期** | 一个短周期的任务（比如 2 周）。这两周大家只专心拍这几场戏，不接新活。 |
| **Blocker (阻碍)** | 🧱 **卡壳了** | “道具没到，戏没法拍”。这事儿卡住了整个进度，必须优先解决。 |
| **Milestone (里程碑)** | 🚩 **阶段性胜利** | “第一季杀青”。标志性的大事，标志着项目上了一个新台阶。 |
