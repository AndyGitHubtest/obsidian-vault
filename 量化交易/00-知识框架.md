# 量化交易知识框架

## 核心术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| Z-Score | Z-Score | `(spread - μ) / σ`，衡量价差偏离均值的程度 |
| 协整 | Cointegration | 两个时间序列的线性组合是平稳的（ADF p < 0.05） |
| 半衰期 | Half-life | `τ = -ln(2) / θ`，均值回归速度，θ 来自 OU 过程回归 |
| 价差 | Spread | 配对两腿价格的线性组合，通常是 `log(P1) - hedge_ratio * log(P2)` |
| 裸仓 | Naked Position | 只有单腿持仓，没有对冲，风险敞口极大 |
| 滑点 | Slippage | 下单价格与预期价格的偏差 |
| 资金费率 | Funding Rate | 永续合约多空双方之间的定期支付 |

## 策略类型

### 1. 统计套利（当前主力）
- **原理**：利用配对价差的均值回归特性
- **信号**：Z-Score 突破阈值进场，回归出场
- **核心**：协整检验 + 动态参数 + 裸仓保护
- **代表**：[[S001-Pro 策略规格说明]]

### 2. 趋势跟踪
- **原理**：跟随价格动量，截断亏损让利润奔跑
- **信号**：均线交叉 / 突破 / 动量指标
- **适合**：大波动、趋势明确的品种

### 3. 事件驱动
- **原理**：利用特定事件（数据发布、升级等）造成的价格异动
- **信号**：事件时间 + 预期偏差

## 核心公式

### Z-Score 计算
```
spread = log(price_A) - hedge_ratio * log(price_B)
z = (spread - rolling_mean) / rolling_std
```

### 动态入场阈值（自适应）
```
z_entry = clip(adaptive_z_min, calculated_z, z_entry_max)
# 市场波动大时提高门槛，波动小时降低门槛
```

### 出场规则
```
z_exit = entry_z * 0.2, clipped to [0.1, 0.5]
# 进场阈值越高，出场阈值也越高（给利润留空间）
```

### 止损
```
Z_STOP = 3.5  # 硬止损，不可移动
```

## 风控体系

| 层级 | 机制 | 参数 |
|------|------|------|
| 配对级 | 流动性过滤 | 日成交量 ≥ 200万U |
| 策略级 | Z-Score 止损 | Z_STOP = 3.5 |
| 账户级 | 日亏损限制 | 每日最大亏损比例 |
| 系统级 | 熔断机制 | 连续亏损触发暂停 |
| 执行级 | 裸仓保护 | 任何异常不产生单边敞口 |

## 回测标准

- **数据要求**：≥ 180 天（4320 根 1h K线）
- **成本**：手续费 0.05% + 滑点 0.05%，4 条腿计算
- **过滤**：Meme币、股票代币、单字母币
- **评估指标**：Sharpe > 2, MaxDD < 15%, WR > 55%
