# 量化交易术语表

> 量化系统开发、实盘运维与风控中的核心术语，按场景分类。
> 用于统一代码命名、文档描述和团队沟通。

## 1. 仓位与状态异常 (Position & State Anomalies)
*描述本地系统与交易所状态不一致的异常，实盘监控核心指标。*

| 术语 | 中文 | 含义 | 代码命名建议 |
|------|------|------|-------------|
| **Ghost Position** | 幽灵仓位 | 交易所独有仓位（本地不知道），需立即接管监控 | `GHOST` |
| **Orphan Position** | 孤儿仓位 | 本地独有仓位（实际已平仓），需清理 | `ORPHAN` |
| **State Divergence** | 状态分歧 | 本地与交易所的持仓/余额不一致 | `DIVERGENT` |
| **Leg Risk** | 单腿风险 | 多腿策略中一腿成交另一腿未成交，导致单边裸仓 | `LEG_RISK` |
| **Stale Price** | 死价格 | 行情长时间未更新，系统误以为价格不变 | `STALE_PRICE` |
| **Phantom Liquidity** | 幽灵流动性 | 订单簿显示有量，实际一吃就撤（虚假挂单） | - |
| **Shadow Position** | 影子仓位 | 策略计算出的理论仓位，但实际未完全成交 | - |
| **Orphan Order** | 孤儿订单 | 本地已发单交易所未收到，或交易所已成交本地不知道 | `ORPHAN_ORDER` |
| **Race Condition** | 竞态条件 | 多进程同时操作同一仓位导致结果不可控（如双重平仓） | - |

## 2. 订单执行与微观结构 (Execution & Microstructure)
*描述订单在市场中的实际遭遇，直接影响策略收益。*

| 术语 | 中文 | 含义 |
|------|------|------|
| **Slippage** | 滑点 | 预期成交价与实际成交价的偏差 |
| **Market Impact** | 冲击成本 | 大单导致价格朝不利方向移动的成本 |
| **Adverse Selection** | 逆向选择 | 成交的往往是对自己不利的价格（被信息优势方收割） |
| **Toxic Flow** | 有毒订单流 | 容易引发逆向选择的订单流，做市商最怕 |
| **Queue Position** | 队列位置 | 订单在交易所订单簿中的排队位置 |
| **Queue Leakage** | 队列泄漏 | 排队时前方订单变化导致自己位置难以精确预测 |
| **Implementation Shortfall** | 执行落差 | 信号产生时的理论收益 vs 实际执行到手的收益差 |
| **Fat Finger** | 肥手指 | 程序/人工输错价格或数量导致的巨额错单 |

## 3. 市场极端状态 (Market Extremes)
*实盘风控必须监控和应对的场景。*

| 术语 | 中文 | 含义 |
|------|------|------|
| **Liquidation Cascade** | 连环爆仓 | 爆仓 → 砸盘 → 触发更多爆仓的恶性循环 |
| **Flash Crash** | 闪崩 | 价格瞬间暴跌/暴涨后快速反弹，通常由算法触发 |
| **Liquidity Black Hole** | 流动性黑洞 | 瞬间买卖盘全部消失，价格直线下坠无承接 |
| **Stop Hunting** | 猎杀止损 | 价格短暂击穿关键位触发大量止损后迅速反弹 |
| **Spoofing** | 幌骗 | 大额虚假挂单制造假象后撤单（非法行为） |
| **Iceberg Order** | 冰山订单 | 只显示部分数量，隐藏真实大小的订单 |

## 4. 策略与数据缺陷 (Strategy & Data Pitfalls)
*回测和策略开发中的常见陷阱。*

| 术语 | 中文 | 含义 |
|------|------|------|
| **Look-ahead Bias** | 前视偏差 | 回测使用了未来才能知道的数据 |
| **Survivorship Bias** | 幸存者偏差 | 只用现存资产回测，忽略已退市资产，结果虚高 |
| **Overfitting** | 过拟合 | 历史数据表现完美但实盘失效（死记硬背） |
| **Signal Decay** | 信号衰减 | 预测信号随时间推移有效性降低 |
| **Regime Change** | 机制转换 | 市场模式根本变化（如低波→高波），策略失效 |
| **Half-life** | 半衰期 | 均值回归策略中价差回归均值一半所需时间 |
| **Warm-up Period** | 预热期 | 策略上线初期稳定指标计算、不实际交易的阶段 |

## 5. 系统与运维 (System & Ops)
*量化基础设施相关术语。*

| 术语 | 中文 | 含义 |
|------|------|------|
| **Heartbeat** | 心跳 | 定期发送的信号，证明连接/服务还活着 |
| **Failover** | 故障转移 | 主系统失效时自动切换到备用系统 |
| **Idempotency** | 幂等性 | 多次执行同一指令结果一致（防重复下单关键） |
| **Reconciliation** | 对账 | 定期比对本地与交易所记录，发现并修复 Ghost/Orphan |
| **Paper Trading** | 模拟交易 | 不投真金白银，跟随实盘数据运行策略验证 |
| **Capacity** | 策略容量 | 策略在不显著影响性能下能管理的最大资金量 |

## 代码中的应用示例

```python
class PositionState(Enum):
    GHOST = "ghost"           # 交易所独有，需接管
    ORPHAN = "orphan"         # 本地独有，需清理
    DIVERGENT = "divergent"   # 数量不一致，需对账
    HEALTHY = "healthy"       # 状态一致

class ExecutionRisk(Enum):
    LEG_RISK = "leg_risk"             # 单腿成交风险
    ADVERSE_SELECTION = "adverse_selection"  # 逆向选择
    SLIPPAGE_EXCEEDED = "slippage_exceeded"  # 滑点超限
    STALE_PRICE = "stale_price"       # 价格长时间未更新

class MarketState(Enum):
    NORMAL = "normal"
    LIQUIDATION_CASCADE = "liquidation_cascade"
    FLASH_CRASH = "flash_crash"
    LIQUIDITY_BLACK_HOLE = "liquidity_black_hole"
```
