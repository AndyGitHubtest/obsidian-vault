# S001-Pro 策略规格说明

> 唯一真相来源。所有代码和回测以此为准。

## 策略概要

| 项目 | 值 |
|------|-----|
| 类型 | 高频统计套利（配对交易） |
| 周期 | 1 分钟 K 线 |
| 持仓 | 15-60 分钟 |
| 交易所 | Binance USDT 永续合约 |
| 成本 | 0.23% 真实成本（4腿 × 0.05% 手续费+滑点 + 资金费） |
| 架构 | Nautilus 风格 → ccxt 执行 |

## Spread 公式

```python
spread = log(leg_a_price) - hedge_ratio * log(leg_b_price)
z = (spread - rolling_mean(spread, window)) / rolling_std(spread, window)
```

- `hedge_ratio`: 通过 OLS 回归计算
- `window`: 滚动窗口，默认 60 根 K 线
- `adf_test`: 协整检验，ADF p-value < 0.05

## 双确认机制

1. **主信号**：Z-Score 突破 entry_z 阈值
2. **确认信号**：连续 N 根 K 线维持方向一致（防假突破）

## 分层进出场

### 进场（两层）
- **Layer 1**（50% 仓位）: Z >= entry_z
- **Layer 2**（50% 仓位）: Z >= entry_z + 0.3

### 出场
- **止盈**：Z 回归至 entry_z * 0.2（clip 到 [0.1, 0.5]）
- **止损**：Z >= Z_STOP（3.5）
- **时间止损**：持仓超过 max_hold 根 K 线强制平仓

## 动态参数

### Z_ENTRY 自适应
```
z_entry = clip(adaptive_z_min, base_z, z_entry_max)
adaptive_z_min: 1.8 ~ 2.8
z_entry_max: 2.8 ~ 3.2（必须 < Z_STOP=3.5）
```

### 根据市场波动率调整
- 波动率低 → 降低门槛（更容易触发）
- 波动率高 → 提高门槛（避免假信号）

## 风控参数

| 参数 | 值 | 说明 |
|------|-----|------|
| Z_STOP | 3.5 | 硬止损，不可移动 |
| 日成交量门槛 | ≥ 200万U | 流动性过滤 |
| 数据要求 | ≥ 180天 | 扫描和回测最低要求 |
| MAX_OPEN_PAIRS | 配置项 | 同时持有配对数上限 |
| 日亏损限制 | 配置项 | 触发后当日停止交易 |

## 裸仓保护（最高优先级）

1. **下单顺序**：确保两腿同时成交或都不成交
2. **异常处理**：网络/重启/延迟/部分成交 → 不产生单边敞口
3. **启动检查**：重启时恢复仓位状态，与交易所对账
