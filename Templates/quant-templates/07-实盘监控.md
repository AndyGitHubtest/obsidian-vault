## 四、应急响应

### 场景 1：出现裸仓
1. **立即：** 记录持仓状态、截图
2. **动作：** 手动对冲裸仓（优先市价单）
3. **分析：** 代码路径审查，找到漏洞
4. **修复：** 修复代码 → 备份 → 测试 → 部署
5. **验证：** 确认不再产生裸仓

### 场景 2：API 断连
1. **立即：** 检查网络、交易所状态
2. **动作：** 重试连接，检查本地缓存
3. **超时：** 超过 1 分钟仍未恢复 → 报警
4. **恢复后：** 检查断连期间的持仓和信号

### 场景 3：策略持续亏损
1. **触发：** 连续 N 天亏损 或 回撤达到 %
2. **动作：** 暂停策略（减小仓位或停止）
3. **分析：** 市场环境是否变化、策略是否失效
4. **决策：** 调整参数 / 暂停 / 下线

### 场景 4：交易所异常
1. **触发：** 大量拒单、延迟极高
2. **动作：** 停止下单，检查交易所状态页
3. **恢复：** 交易所恢复后逐步放量
