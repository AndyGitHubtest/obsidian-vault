## 三、数据库设计
### K线表 (klines)
| 字段 | 类型 | 说明 |
|------|------|------|
| symbol | TEXT | 交易对 (BTCUSDT) |
| timestamp | INTEGER | 时间戳 (ms) |
| open | REAL | 开盘价 |
| high | REAL | 最高价 |
| low | REAL | 最低价 |
| close | REAL | 收盘价 |
| volume | REAL | 成交量 |
| amount | REAL | 成交额 |

```sql
CREATE TABLE klines (
    symbol TEXT NOT NULL,
    timestamp INTEGER NOT NULL,
    open REAL NOT NULL,
    high REAL NOT NULL,
    low REAL NOT NULL,
    close REAL NOT NULL,
    volume REAL NOT NULL,
    amount REAL NOT NULL,
    PRIMARY KEY (symbol, timestamp)
);
```

## 四、数据质量
### 检查项
- [ ] 缺失 K 线检测（时间不连续）
- [ ] 异常值检测（价格突变 >10%）
- [ ] 成交量为 0 的 K 线
- [ ] 高低价穿越检查（high < open 或 low > open）
- [ ] 重复数据检测

### 修复策略
| 问题 | 处理方式 |
|------|----------|
| 缺失 K 线 | 用上一根填充 / 标记跳过 |
| 异常值 | 剔除 / 截断 |
| 重复数据 | 去重 |
